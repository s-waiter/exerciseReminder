## 🎯 程序简介

DeskCare 是一款专为办公人群设计的智能健康提醒软件，主要功能包括：

- **久坐提醒**：定时提醒您起身活动，预防职业病
- **午休模式**：提供沉浸式午休体验，助您快速恢复精力
- **时光足迹**：记录您的工作状态，生成详细的时间报告
- **智能日程**：管理生活中的各种提醒事项
- **整点报时**：科技感十足的整点提醒特效
- **弹幕提醒**：创新的提醒方式，既不影响工作又无法忽视

## 🚀 快速开始

### 第一步：启动程序

1. 双击桌面图标或从开始菜单启动 DeskCare
2. 程序将自动最小化到系统托盘，在屏幕右下角可以看到我们的图标
3. 首次启动时，程序会显示主设置界面

### 第二步：基础设置

1. **设置提醒间隔**：建议设置为45分钟，这是最适合办公人群的间隔
2. **开启开机自启**：确保每次开机自动运行，不会忘记使用
3. **选择提醒方式**：可以选择全屏提醒或弹幕提醒

### 第三步：开始使用

设置完成后，程序会在后台运行，定时弹出提醒。您可以：

- 点击托盘图标查看剩余时间
- 右键托盘图标访问更多功能
- 根据提醒进行相应的休息或活动

## 🔧 核心功能详解

### 1. 久坐提醒

**功能说明**：
久坐提醒是 DeskCare 的核心功能，通过定时全屏提醒帮助您养成良好的工作习惯。

**使用方法**：
- 默认每45分钟提醒一次
- 提醒时会弹出全屏窗口，显示精美的背景图片
- 可以选择"稍后提醒"（推迟5分钟）或"完成运动"

**设置选项**：
- 自定义提醒间隔（30-120分钟）
- 开启强制运动模式（必须停留指定时间才能关闭）
- 选择提醒音效和背景图片

### 2. 午休模式

**功能说明**：
专为午休场景设计的沉浸式体验，帮助您在办公室获得高质量的休息。

**使用方法**：
1. 点击托盘图标 → 选择"开始午休"
2. 设置午休时长（默认30分钟）
3. 进入全黑休息界面，显示极简时钟
4. 长按鼠标左键3秒或按住ESC键3秒退出

**特色功能**：
- **极致暗黑**：纯黑背景，适配OLED屏幕，护眼省电
- **微光时钟**：极低亮度的数字时钟，位置自动微调防烧屏
- **日出唤醒**：结束前2分钟逐渐变亮，自然唤醒
- **白噪音**：提供多种环境音帮助入睡

### 3. 时光足迹

**功能说明**：
记录和分析您的工作状态，生成详细的时间报告，帮助您了解自己的工作习惯。

**使用方法**：
1. 点击托盘图标 → 选择"时光足迹"
2. 查看今日/本周/本月的时间统计
3. 分析工作、休息、暂停等状态分布
4. 导出报告用于长期跟踪

**显示内容**：
- 时间线图表：直观显示一天的时间分配
- 统计数据：总工作时长、休息次数、平均工作时长等
- 趋势分析：长期数据对比，发现改善空间

### 4. 智能日程

**功能说明**：
全场景智能日程管理，支持复杂的时间规则和多种提醒类型。

**使用方法**：
1. 点击托盘图标 → 选择"提醒事项"
2. 点击"添加提醒"创建新的日程
3. 设置提醒内容、时间、重复规则
4. 选择提醒样式（甜蜜/严肃/温馨/紧急）

**支持类型**：
- **工作日提醒**：仅周一至周五生效
- **节假日提醒**：针对特殊日期的提醒
- **循环提醒**：支持"每两周的周三"等复杂规则
- **倒计时事件**：如生日、纪念日等

### 5. 整点报时

**功能说明**：
每逢整点触发科技感十足的视觉特效，让时间流逝变得有趣。

**特效类型**：
- 24种不同的科幻风格特效
- 赛博朋克、抽象艺术等主题
- 随机播放，每小时都有惊喜

**设置方法**：
在设置界面开启"整点报时"功能（默认开启）

### 6. 弹幕提醒

**功能说明**：
创新的提醒方式，将提醒内容转化为滚动的弹幕，既不影响工作又无法忽视。

**弹幕特点**：
- **全屏穿透**：弹幕在屏幕最顶层滚动，背景完全透明
- **多屏同步**：支持多显示器同步显示
- **升级协议**：根据用户响应情况，弹幕密度和颜色会动态变化
- **多种风格**：二次元、黑客帝国、禅意等主题

## ⚡ 快捷操作

### 托盘图标操作

**左键单击**：
- 显示/隐藏主设置界面
- 查看剩余时间

**右键菜单**：
- 开始午休
- 查看时光足迹
- 管理提醒事项
- 程序设置
- 退出程序

### 快捷键

**全局快捷键**：
- `Ctrl + Shift + D`：显示/隐藏主界面
- `Alt + N`：快速开始午休模式
- `Esc`：退出全屏提醒（如未开启强制模式）

**午休模式**：
- 长按鼠标左键3秒：退出午休
- 按住ESC键3秒：退出午休
- 任意键：显示/隐藏时钟

### 提醒窗口操作

**全屏提醒**：
- 点击"稍后提醒"：推迟5分钟
- 点击"完成运动"：结束本次提醒
- 按ESC键：退出（如未开启强制模式）

**弹幕提醒**：
- 点击"我知道了"：清除弹幕
- 点击"推迟X分"：延迟提醒
- 划过金色弹幕：游戏化完成打卡

## ❓ 常见问题

### Q1: 程序无法开机自启动？

A: 请检查以下几点：
1. 确认已在设置中开启"开机自启"选项
2. 检查杀毒软件是否阻止了程序自启动
3. 确保程序有管理员权限运行

### Q2: 提醒时没有声音？

A: 解决方法：
1. 检查系统音量是否开启
2. 在设置中确认已开启音效
3. 检查是否开启了静音模式
4. 尝试重新设置音效文件

### Q3: 多显示器下提醒显示异常？

A: 程序支持多显示器，如遇到问题：
1. 在设置中重新选择主显示器
2. 重启程序让配置生效
3. 确保显卡驱动已更新到最新版本

### Q4: 如何备份和恢复设置？

A: 设置文件保存在：
- Windows: `C:\Users\[用户名]\AppData\Roaming\DeskCare\`
- 备份整个文件夹即可保存所有设置
- 恢复时替换同名文件夹

### Q5: 程序占用内存过高？

A: 优化建议：
1. 关闭不使用的功能（如整点报时）
2. 减少同时显示的弹幕数量
3. 定期清理时光足迹的历史数据
4. 更新到最新版本获得性能优化
