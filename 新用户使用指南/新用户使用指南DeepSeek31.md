## 🚀 快速入门

### 首次启动
1. **启动程序**：双击 DeskCare.exe 启动应用
2. **系统托盘**：程序启动后会自动最小化到系统托盘区
3. **托盘图标**：在任务栏右下角找到 DeskCare 图标

### 基本操作
- **左键单击**托盘图标：打开/关闭主界面
- **右键单击**托盘图标：显示快捷菜单
- **拖拽**主界面：移动窗口位置

## 🖥️ 主界面功能

### 正常模式 (280×420px)
主界面显示完整的倒计时圆环和功能卡片：

```
[ DeskCare 标题栏 ]
    [ 倒计时圆环 ]
[ 状态显示区域 ]
[ 功能卡片区域 ]
```

### 功能卡片区域包含：
- **⏸/▶ 暂停/继续**：控制计时器状态
- **📅 提醒事项**：管理您的日程安排
- **☾ 午休助眠**：进入午休模式
- **📊 时光足迹**：查看活动统计

### 迷你模式/悬浮球 (120×120px)
- **双击**主界面：切换为迷你悬浮球模式
- **位置**：默认显示在屏幕右上角
- **特性**：半透明、置顶显示、鼠标悬停时显示更多信息

## ⏰ 核心功能详解

### 1. 久坐提醒
**默认设置**：每 45 分钟提醒一次

**提醒方式**：
- 全屏覆盖提醒界面
- 优美的粒子动画效果
- 5分钟运动引导
- "稍后提醒"按钮（延迟5分钟）

**自定义设置**：
- 打开设置面板（右键菜单 → 设置）
- 调整工作时长：30-60分钟
- 立即生效，无需重启

### 2. 午休助眠模式
**进入方式**：
- 主界面点击"☾ 午休助眠"卡片
- 右键菜单选择"午休助眠"
- 快捷键：四击悬浮球

**功能特点**：
- 🖥️ 全黑屏幕保护（OLED友好）
- ⏰ 极简时钟显示（防烧屏）
- 🔇 自动屏蔽通知
- 🌅 自然唤醒（光线渐变）
- 🔊 环境白噪音（雨声、风声等）

**退出方式**：长按屏幕 2 秒

### 3. 提醒事项管理
**打开方式**：
- 主界面点击"📅 提醒事项"卡片
- 迷你模式下右键菜单选择"提醒事项"

**功能特性**：
- 📝 创建四种类型提醒：工作、生活、纪念日、健康
- 🎨 智能主题配色
- 🔔 多提醒方式：弹窗、弹幕、全屏
- ⏰ 重复提醒设置
- 📊 分类管理

### 4. 时光足迹统计
**打开方式**：
- 主界面点击"📊 时光足迹"卡片
- 右键菜单选择"时光足迹"

**统计内容**：
- 📈 每日活动时间线
- ⏱️ 各类活动时长统计
- 🎯 健康目标完成情况
- 📅 历史数据查询
- 🎨 可视化图表展示

## ⚡ 快捷操作

### 鼠标操作
| 操作方式 | 功能 |
|---------|------|
| **单击**悬浮球 | 暂停/继续计时 |

| 快捷键 | 功能 |
|--------|------|
| `Esc` | 关闭当前窗口 |
| `Alt+F4` | 退出程序（慎用） |

- **向上滑动**：显示更多选项
- **向下滑动**：隐藏界面
- **圆形滑动**：调整透明度

## ❓ 常见问题

### Q1: 如何完全退出程序？
A: 右键点击托盘图标 → 选择"退出"

### Q2: 提醒没有弹出怎么办？
A: 检查系统通知权限，或尝试重启程序

### Q3: 如何调整提醒音量？
A: 目前提醒为视觉提示，无声音提示

### Q4: 支持开机自启吗？
A: 支持！在设置中开启"开机自动启动"

### Q5: 数据存储在哪里？
A: 所有数据本地存储，保障隐私安全
