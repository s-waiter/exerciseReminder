## 2. 修改文件
### a. `assets/qml/SettingsOverlay.qml`
- **逻辑调整**：
  - 修改中间数值区域的 `onClicked` 事件。
  - 移除 `timerEngine.workDurationMinutes = 45`。
  - 改为调用 `timerEngine.startWork()`。该函数在 C++ `TimerEngine` 类中实现，用于重置计时器并开始工作。

### b. `assets/qml/Main.qml`
- **图标替换**：
  - 定位到 `intervalCard`（提醒事项入口）。
  - 移除原有的 `Text { text: "📅" ... }`。
  - 新增 `Item` 组件，使用 QML `Rectangle` 原生绘制纯白扁平化日历图标。

    - 主体：14x13 的圆角矩形，白色边框 (1.5px)，透明填充。

  - **视觉对齐**：图标整体尺寸控制在 16x16，与右侧“午休助眠”按钮的字体图标视觉重心保持一致。
